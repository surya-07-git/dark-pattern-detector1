Quickstart: How to Load the Extension in Google Chrome

  1. Open Google Chrome and navigate to chrome://extensions/
  2. Enable Developer mode using the toggle switch in the top-right corner.
  3. Click the Load unpacked button in the top-left toolbar.
  4. Select the directory: c:\mini project\extension\
  5. Open the Positive Cases link above. The extension badge will immediately illuminate with the number of detected dark patterns!
  6. Click the extension shield icon to open the popup, filter by category, and click Inspect on Page to see non-destructive element highlighting.
